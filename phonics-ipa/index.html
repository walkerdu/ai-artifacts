单元音 12个

嘴巴保持一个形状不动就发完的音。带「ː」的要拖长，不带的要短促。

双元音 8个

两个音「滑」过去，像滑滑梯一样，中间不能停。

爆破音 6个

先把气憋住，再「砰」地放出来，像小炮仗。

摩擦音 10个

气流从小缝里「呼呼」挤出来，声音可以一直拖着。

破擦音 6个

先爆破再摩擦，两个动作连起来。

鼻音 3个

捏住鼻子就发不出来了，试试看！

半元音 + 边音 3个

舌头两边漏气（/l/），或者像元音一样滑动（/w/ /j/）。

4条黄金拼读规则

规则 1 · CVC 三明治（辅音-元音-辅音）→ 元音发短音

只要单词是「辅音 + 元音 + 辅音」的夹心结构，中间那个元音一定发短音。

c-a-t → catd-o-g → dogs-i-t → sitb-u-s → bus

规则 2 · 魔法 e（Magic e）→ 把元音拉长，自己不出声

词尾加一个 e，它自己不发音，却像魔法棒一样把前面的元音变成「字母本名」。

cap 帽子 → cape 斗篷kit → kite 风筝hop → hope 希望

规则 3 · 两个元音站一起 → 第一个说话，第二个不出声

元音组合常常发新的长音，口诀：「When two vowels go walking, the first one does the talking.」

ai/ay → /eɪ/ rain, playea/ee → /iː/ sea, treeoa → /əʊ/ boatoi/oy → /ɔɪ/ coin, boy

规则 4 · 两个辅音手拉手 → 只发一个新音

这些组合不能拆开读，要当成一个整体。

sh → /ʃ/ 嘘ch → /tʃ/ 吃th → /θ/ /ð/ 咬舌ph → /f/ng → /ŋ/wh → /w/

自然拼读六步走

1

认字母音

26个字母的「发音」而不是「名字」，5个元音各会两种音。

2

拼两个音

c-a → ca，a-t → at，先把两个音粘起来。

3

拼 CVC 词

d-o-g → dog，能读出完整的单音节词。

4

拆多音节

sw-ea-t-er → sweater，长词先切块再拼。

5

听音写词

听到读音能自己拼出来，从「读」跨到「写」。

6

自主阅读

词汇量爆发，可以自己读英文绘本和故事书。
